📺 Установка на TV

Добавьте иконку VIDAA TV Player на главный экран телевизора Toshiba / Hisense

Нажмите кнопку выше для быстрой установки иконки на рабочий стол ТВ

📺 Способ 1: Установка через браузер ТВ

1. Откройте эту страницу на телевизоре в браузере.
2. Нажмите синюю кнопку «Добавить иконку» выше.
3. Подтвердите добавление — иконка плеера появится на рабочем столе ТВ.

🚀 Способ 2: Запуск через Media Station X (MSX)

Если на вашем ТВ установлено приложение Media Station X:
