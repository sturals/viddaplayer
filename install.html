📺 Быстрый запуск на VIDAA TV

На операционной системе VIDAA OS (Hisense / Toshiba) есть 2 удобных способа запуска плеера без постоянного ввода адреса:

🚀 Способ 1: Запуск в 1 клик через Media Station X (Рекомендуется)

1. Откройте встроенный магазин приложений на ТВ и установите бесплатное приложение Media Station X.
2. Запустите Media Station X → откройте Settings → Start Parameter → Setup.
3. Укажите следующий адрес плеера:

viddaplayer.vercel.app

Иконка плеера появится прямо на главном экране MSX!

⭐ Способ 2: Закладки в браузере ТВ

1. Нажмите на пульте ТВ или в браузере иконку «Меню» (≡) или «Закладки» (⭐).
2. Выберите пункт «Добавить в закладки» или «Закрепить на стартовой странице».
3. Плеер будет всегда доступен на стартовом экране браузера ТВ.

▶ Открыть плеер прямо сейчас
