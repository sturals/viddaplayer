# VIDAA TV Player

Универсальный веб-видеоплеер для Smart TV на базe **VIDAA OS** (Toshiba, Hisense) с поддержкой управления скоростью воспроизведения (с сохранением тональности звука), переключением аудиодорожек, D-Pad навигацией с пульта и HLS-стримингом.

📖 **Полная подробная инструкция по установке и настройке находится в файле [INSTRUCTION.md](file:///c:/Users/sulei/Desktop/antigrav/myprojects/vidplayer/INSTRUCTION.md).**

## 🚀 Быстрый запуск на ПК
```bash
npx serve -p 3000
```
Открыть в браузере: `http://localhost:3000`

## 📁 Структура проекта
- `index.html` — Разметка 10-foot UI и видеоплеера
- `style.css` — Стили Glassmorphism, навигационные фокусы и анимации
- `app.js` — Движок HLS.js, скорость 0.25x-3.0x, управление пультом, история
- `manifest.json` — PWA манифест
- `favicon.svg` — Иконка приложения
- `INSTRUCTION.md` — Инструкция по настройке на ТВ (Media Station X / VIDAA Browser)
